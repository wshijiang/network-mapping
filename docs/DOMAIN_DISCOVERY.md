# 证书透明度域名发现

控制台“域名发现”支持从 crt.sh 搜索种子域及其后代，补充完整证书 SAN，展示证书关联并将选中名称交给现有 DNS 扫描器验证。证书记录不证明资产归属、当前解析或服务存活。

## 使用

1. 输入明确种子域，默认不向上扩大到注册域。例如 `api.example.com` 只查询该名称和其后代。
2. 勾选“补充完整证书与关联域名”后，按返回证书 ID 获取证书并解析 DNS SAN。搜索 JSON 的 name_value 仅是查询匹配名称，页面不会把它当成完整 SAN。
3. 后台作业完成后查看域名、子域名、同证书关联或证书通配模式。每条名称均能关联证书来源；域名链接仅查看当前用户已有完整 SAN 证据，不自动请求外部服务或递归发现。
4. 选择最多 500 个具体域名执行“DNS 验证”。任务为现有 dns_records profile；通配模式不能直接提交，命中域名排除规则的目标禁止提交。重复提交同一作业中的域名复用已有任务。解析记录和状态在对应任务详情中查看。

crt.sh endpoint 固定为 `https://crt.sh/`，需允许后端出站访问；读取系统 HTTPS 代理并保持证书校验和禁重定向。无需给扫描器新增协议。真正的 DNS 验证仍需要在线且支持 dns_records 的扫描器；进一步扫描解析 IP 时应使用现有扫描流程和 CIDR 授权策略。

## 关系与完整性

- 子域名按点标签边界判断；相似后缀不是子域。
- 同证书关联只来自解析出的完整 DNS SAN；不按相同签发者、共享 IP 或相同组织字段推断归属。
- `*.example.com` 单独显示为证书通配模式，不展开虚构主机；去掉通配符后的名称也不会被当成已发现主机。
- 证书有效期、查询时间、DNS 观测时间是不同维度。过期证书仍能提供历史线索，不表示域名失效。
- 部分源查询或证书补充失败会显示 partial，已有结果可查看。数量截断、SAN 补充失败和上游错误单独展示；不会宣称是完整域名清单。

## 预算与恢复

每个用户最多 3 个活动作业、每小时 20 次新作业，全局最多 100 个活动作业。进行中的同种子同模式作业会复用；成功/部分结果默认缓存 24 小时；强制刷新仍有 5 分钟同查询冷却。首次版本集中串行处理，单作业最长外部查询预算 100 秒，租约 3 分钟，最多尝试 3 次，按次数乘 30 秒退避。重启后过期租约可以恢复。

每个 JSON 响应最多 16 MiB、处理最多 20,000 条来源行，每作业最多 50 个证书记录和 5,000 个名称；单证书下载最多 1 MiB；同一快照的证书名称总量最多 10,000 项，关系聚合也有同等预算和最多 50 个证书记录。超过上限明确标记。证书关系详情最多合并最近 20 个匹配快照；页面有截断提示。

## 存储与权限

PostgreSQL 的 domain_discovery_job 保存作业、所有者、租约、配额和摘要；domain_discovery_dns_target 保存 DNS 提交的幂等关联。Elasticsearch 的 `<dns_record_index>-discovery-v1` 保存有界作业证据快照，以作业 UUID 为文档 ID，记录所有者、种子、名称、证书指纹和完整性。证据独立于 DNS RR 索引，不能制造 DNS response 或 TTL。ES 写入使用尝试次数的外部版本，防止过期执行覆盖新尝试；完成状态在写入后更新。取消后的结果不会通过作业读取接口公开。

这是首版的有界快照模型，不引入图数据库。关系查询在用户拥有的已完成作业范围内聚合；管理员也默认只读取自己的发现。公开 CT 证据不会扩大内部扫描结果的可见范围。所有写接口沿用登录和 CSRF 保护，创建与 DNS 提交写入审计。外部错误只保留固定分类。

初始化 SQL 与 `source/database/migrate_domain_discovery.sql` 均幂等。备份需要同时保留 PG 作业元数据与 ES 证据索引；只恢复 PG 时，已完成作业的证据读取会报告不可用，不伪造空结果。首版不自动清理历史证据，运维可按作业/证据关联制定保留策略。

## API

- POST /api/domain-discovery/jobs：seed、include_related、refresh；返回 job 与 reused。
- GET /api/domain-discovery/jobs：当前用户最近 100 个作业。
- GET /api/domain-discovery/jobs/{id}：作业摘要。
- GET /api/domain-discovery/jobs/{id}/results：证据、当前排除项、已提交 DNS 任务。
- POST /api/domain-discovery/jobs/{id}/cancel：取消排队或执行中的发现；不能撤回已发出的外部查询。
- POST /api/domain-discovery/jobs/{id}/dns-tasks：domains 数组，1–500 项，必须属于该作业的具体发现名称。
- GET /api/domains/{domain}/relations：当前用户已存域名及其子域的已有证书关系，返回来源作业与完整性；根域本身不在 SAN 时仍能展示已发现的子域。

## 验证

Rust 测试覆盖匹配身份与完整 SAN 的区别、子域边界、通配模式、跨域证据、大小限制和用户隔离；PostgreSQL 测试使用独立 schema。前端工具测试覆盖排除、通配项、重复提交和 500 项选择上限。实际部署仍需确认 crt.sh 可访问性及来源限流；本地 fixture 不能证明外部服务当前可用。
